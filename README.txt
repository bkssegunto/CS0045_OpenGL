Module 1 OpenGL Workspace

1. Open this folder in Visual Studio Code.
2. Put each exercise source file in the M1 folder, for example Q01.cpp.
3. Open the .cpp file you want to build.
4. Press Ctrl+Shift+B to compile it.
5. Press F5 to build and run it under the debugger.

Installed toolchain:
- MSYS2 UCRT64 GCC and G++
- MSYS2 UCRT64 GDB
- FreeGLUT for UCRT64
- Visual Studio Code C/C++ extension

The configurations use C:\msys64\ucrt64\bin and link against freeglut,
opengl32, and glu32 as required by the laboratory manual.
